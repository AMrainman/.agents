# Torna 类型 → TypeScript / Mock 数据映射

## 基础类型

| Torna 类型                    | TypeScript 类型 | Mock 值                  | 说明                      |
| ----------------------------- | --------------- | ------------------------ | ------------------------- |
| `string`                      | `string`        | `"mock_string"`          | 通用字符串默认值          |
| `int`                         | `number`        | `1`                      | 整数                      |
| `long`                        | `number`        | `1`                      | 长整数，与 `int` 同等处理 |
| `number` / `float` / `double` | `number`        | `1.5`                    | 浮点数                    |
| `boolean`                     | `boolean`       | `true`                   | 布尔值                    |
| `date`                        | `string`        | `"2024-01-01"`           | 日期字符串                |
| `datetime`                    | `string`        | `"2024-01-01T00:00:00Z"` | 日期时间字符串            |
| `timestamp`                   | `number`        | `1704067200000`          | 时间戳（毫秒）            |

## 复合类型

| Torna 类型                | TypeScript 类型     | Mock 值                        | 说明                                        |
| ------------------------- | ------------------- | ------------------------------ | ------------------------------------------- |
| `array` / `list`          | `T[]`               | `[element1, element2]`         | 含 1~2 个元素的数组，元素递归按本表规则生成 |
| `object` / 自定义对象类型 | `object` / 具体接口 | `{ field1: ..., field2: ... }` | 递归展开内部字段                            |
| `map` / `dict`            | `Record<string, T>` | `{ "key1": value1 }`           | 生成一个键值对示例                          |

## 特殊处理规则

- **枚举类型**：Torna 若标注了枚举值，取第一个枚举值作为 mock。
- **可空字段**（`required: false`）：70% 概率生成值，30% 概率生成 `null` 或 `undefined`，使 mock 更真实。
- **嵌套深度限制**：超过 5 层的嵌套对象，第 5 层及以下用 `{ /* ... */ }` 占位，避免生成过大的 mock 数据。
- **数组元素数量**：默认生成 1~2 个元素。若字段名含 `list`、`items`、`records`，生成 2~3 个元素。
